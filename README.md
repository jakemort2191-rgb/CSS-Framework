# CSS-Framework
A practice project exploring CSS frameworks and how they can be used to build responsive, consistent web layouts with less custom CSS.
# CSS Frameworks

## About This Project

This project is part of my software and web development course. I'm using it to learn how CSS frameworks work and how they can make building websites quicker and easier.

I'll be exploring pre-built styling classes and layout tools to see how they can be used to create a consistent design without having to write every CSS rule from scratch.

## What I'm Working On

- **CSS frameworks** – understanding what frameworks are and how they help with web development.
- **Bootstrap** – experimenting with its grid system, buttons, navigation and other components.
- **Responsive layouts** – using framework classes to make pages work across different screen sizes.
- **Spacing and alignment** – using utility classes to control margins, padding and positioning.
- **Components** – working with pre-built elements such as cards, alerts and navigation bars.
- **Custom styling** – adding my own CSS to adjust framework components and make the design my own.
- **Code organisation** – understanding how frameworks fit into a website's HTML and CSS.

## Technologies Used

- HTML5
- CSS3
- Bootstrap

## What I've Learned

This project gives me the chance to practise using a CSS framework and compare it with writing styles from scratch.

I'm learning how framework classes can speed up development, help maintain consistent styling and make responsive layouts easier to build. I'm also exploring when custom CSS is useful alongside a framework.

## How to View the Project

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Explore the layout and components created using the framework.

If the project uses Bootstrap through a CDN, an internet connection will be needed for the framework styles to load.
